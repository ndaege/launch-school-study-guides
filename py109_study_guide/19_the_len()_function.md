The `len()` function is used to determine the length of collections and sequences, that is to say, how many elements/characters/numbers exists in the object. 
```python
my_list = [1, 2, 3]
my_dict = {'a': 1, 'b': 2, 'c': 3}
my_str = 'elephant'
my_range = list(range(1, 76))

print(len(my_list))   # prints 3
print(len(my_dict))   # prints 3
print(len(my_str))    # prints 8
print(len(my_range))  # prints 75
```
